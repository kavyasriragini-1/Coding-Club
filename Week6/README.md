# 📆Week6

## 📚 Topics Covered

### 🎨 1. Design Fundamentals
* **User Interface Design Fundamentals**: Core principles of creating effective and visual UI.
* **User-Centered Design**: Designing with the user's needs, behavior, and goals in mind.
* **Common Design Tools**: Exploring industry-standard tools used for wireframing and prototyping.

### 📏 2. Absolute and Relative Units
* **Working with Relative and Absolute Units**: Understanding how to size elements effectively using units like `px`, `em`, `rem`, `%`, `vw`, and `vh`.
* **Lab Project**: Built an event flyer


### 🎭 3. Pseudo-Classes and Pseudo-Elements
* **Working with Pseudo-Classes & Pseudo-Elements**: Styling elements based on state (e.g., `:hover`, `:focus`) or targeting specific parts of elements (e.g., `::before`, `::after`).
* **Workshop Project**: Design a greeting card

## 🛠️ Technologies Used
* **HTML5**
* **CSS3**
* **UI/UX Design Concepts**
